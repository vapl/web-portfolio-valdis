  <IntroCard

    title="From manual exports to automatic ERP reporting"
    invert={true}
    maxWidth="xl"
  >
    I built a Next.js dashboard connected to Horizon ERP data in Microsoft SQL
    Server. It gives management a current view of quotations, orders and KPIs,
    replacing repeated CSV exports and spreadsheet preparation.

    Development, testing and adjustments took place over three days, working in
    sessions rather than full-time.

    The dashboard extends an internal production system already used by designers
    and design engineers, making operational reporting available within the same
    environment.
  </IntroCard>

<Section id="challenge">
  <IntroCard
    eyebrow="The challenge"
    title="Finding the right data in an unfamiliar ERP database"
    invert={true}
    maxWidth="xl"
  >
    With no ready-made API or dataset, I investigated Horizon&apos;s Microsoft SQL
    Server tables, mapped their relationships and wrote queries for quotations,
    orders and KPIs.

    Data investigation and retrieval spanned two of the three development days.
    The integration had to work alongside the existing ERP system without
    disrupting employees&apos; daily work.
  </IntroCard>
</Section>

<Section id="problem" title="Problem">
  <ul className="list-disc space-y-3 pl-6 text-lg text-text/80">
    <li>CSV exports from several systems needed manual preparation.</li>
    <li>Data was sorted and combined in Excel for a Power BI report.</li>
    <li>Reports lagged behind source data that refreshed hourly or more often.</li>
    <li>The same preparation had to be repeated each reporting cycle.</li>
  </ul>
  <PullQuote>
    Useful reporting starts with understanding the company&apos;s data and turning
    it into information people can act on.
  </PullQuote>
</Section>

<Section id="solution">
  <IntroCard
    eyebrow="Solution"
    title="Automatic reporting from existing company data"
    invert={true}
    maxWidth="xl"
  >
    SQL queries retrieve and aggregate the required Horizon data. The application
    processes it automatically and presents quotations, orders and business KPIs
    with filtering, period comparison and CSV export.

    The dashboard adds an analytical layer to the existing ERP data. Users can
    review current figures without rebuilding the spreadsheet workflow each
    time they need an update.
